# Quillbox Notes API

A small REST API for creating and managing notes. Notes are held in an in-memory `Map` and are cleared when the server restarts.

## Run

```sh
npm install
npm start
```

The server listens on `http://localhost:3000` by default. Set `PORT` to use another port.

## Test

```sh
npm test
```

## Endpoints

| Method | Path | Description | Success status |
| --- | --- | --- | --- |
| `POST` | `/notes` | Create a note | `201 Created` |
| `GET` | `/notes` | Retrieve all notes | `200 OK` |
| `GET` | `/notes/:id` | Retrieve a note by id | `200 OK` |
| `PUT` | `/notes/:id` | Update a note | `200 OK` |
| `DELETE` | `/notes/:id` | Delete a note | `204 No Content` |

Notes contain an integer `id`, `title`, `content`, `createdAt`, and `updatedAt`. Timestamps are ISO strings generated by the server. Create and update requests accept `title` and `content`; client-supplied ids and timestamps are ignored. Errors are JSON objects in the form `{ "error": "message" }`.

## Example

```sh
curl -i -X POST http://localhost:3000/notes \
  -H "Content-Type: application/json" \
  -d '{"title":"First","content":"Hello"}'

curl -i http://localhost:3000/notes
curl -i http://localhost:3000/notes/1

curl -i -X PUT http://localhost:3000/notes/1 \
  -H "Content-Type: application/json" \
  -d '{"title":"First edited","content":"Updated"}'

curl -i -X DELETE http://localhost:3000/notes/1
```

Import `Quillbox Notes API.postman_collection.json` into Postman to run the complete request sequence.
